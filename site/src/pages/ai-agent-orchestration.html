What is AI agent orchestration?

You're running AI coding agents. Maybe Claude Code, maybe Codex, maybe both. They're scattered across terminals, machines, maybe servers. Orchestration is how you bring them together.

The Problem

Agents are great.
Managing them isn't.

Scattered terminals

One agent in iTerm, another in VS Code, a third on your VPS. Which one needs attention right now?

No mobile access

Agent needs approval. You're at lunch. Either you run back to your laptop or the agent sits there waiting.

Provider fragmentation

Claude Code has one workflow, Codex has another. Different commands, different approval flows, different mental models.

No visibility

How many tokens have you used today? What's your rate limit headroom? Which sessions are still running?

The Solution

One dashboard.
Every agent.

OrbitDock is an orchestration layer. It connects to your agents — wherever they run, whatever provider — and gives you a unified view.

Use Cases

Who needs orchestration?

Remote-first teams

Research

Capabilities

What orchestration gives you

Unified monitoring

Every agent, every machine, every provider. One screen. Color-coded status tells you what needs attention.

Unified approval

Same keyboard shortcuts whether it's Claude or Codex. Same diff view. Same risk badges. No context switching.

Mobile control

Native iOS app. Push notifications when agents need you. Approve, deny, steer — from anywhere.

Multi-server

Laptop, VPS, home lab. Connect them all. Sessions merge into one view.

Usage tracking

Token counts, cost estimates, rate limit gauges. Per provider, per session, in real-time.
