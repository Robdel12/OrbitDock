What OrbitDock Adds

Everything you've been missing

Native Mac app

Real Swift app in your dock. See all sessions at a glance. Keyboard shortcuts. Not a terminal tab — a proper dashboard.

iPhone & iPad apps

Claude needs approval? You're not at your desk? Push notification, tap, review the diff, approve. Done.

Multi-session view

Running 3 agents? See them all. Color-coded status: cyan for working, coral for needs approval, purple for questions.

Approval queue

Triage pending approvals with keyboard shortcuts. y approve, n deny, ! always-allow. No mouse needed.

Rate limit visibility

Claude's sliding windows visualized. See per-minute, per-hour, per-day usage. Know your headroom before starting another agent.

Multi-server

Claude Code on your laptop and a VPS? Both appear in the same dashboard. One view, every machine.
