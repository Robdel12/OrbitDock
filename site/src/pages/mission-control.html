The Loop

How it works

1

Poll your tracker

OrbitDock watches Linear or GitHub for issues matching your criteria. New issue? It goes in the queue.

2

Dispatch an agent

Pick the right provider (Claude or Codex), create a worktree, render the prompt, start the session. All automatic.

3

Handle failures

Agent stalled? Kill it, retry with fresh context. Rate limited? Exponential backoff. Real blocker? Flag it for human review.

4

Open the PR

Work done? Agent opens a PR, links the issue, moves it through your workflow. You review when you're ready.

Configuration

One file. Full control.

Define your mission in MISSION.md. Everything else is automatic.

# MISSION.md
tracker: linear
project: BACKLOG
labels: [agent-ready]
strategy: priority # Claude first, Codex overflow
max_concurrent: 3
stall_timeout: 600s
max_retries: 3
on_complete: open_pr
